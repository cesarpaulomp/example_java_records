# Example Java Records

Este projeto é um exemplo de uso de Records em Java, demonstrando como utilizar essa funcionalidade moderna da linguagem para criar estruturas de dados imutáveis de forma concisa.

## Tecnologias

- **Java 25**
- **Spring Boot**
- **JSONPlaceholder API**

## Descrição

Construído com Spring Boot, este projeto usa JSONPlaceholder para demonstrar operações CRUD com Records, mostrando como consumir APIs REST externas e mapear dados para Records Java de forma eficiente.

Foi projetado para rodar com Java 25, aproveitando as mais recentes funcionalidades da linguagem.

## Requisitos

- Java 25 ou superior
- Maven 3.6+

## Como executar

```bash
mvn install
mvn spring-boot:run
```
